把方法包起來

Skills 下載

把工作方法做成可以 clone 的 Claude Skills 技能包。Claude Code、Codex、Cowork、ChatGPT 都能讀。MIT 授權，免費商用。

怎麼用？

三步驟把技能包接上你的 AI

  1. 到 GitHub repo 按 Code → Download ZIP，或 git clone 整包到本機
  2. 把整個資料夾放到你 Agent 的 .claude/skills/ 或對應的技能包資料夾裡
  3. 跟 AI 講對應的觸發詞，AI 會自動載入技能包並照流程走

不熟 GitHub 沒關係，每個技能包的 README 都有使用說明，照著做就會跑。
